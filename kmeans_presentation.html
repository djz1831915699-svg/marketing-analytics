THE METHOD

Assign. Update. Repeat.

01

Choose K

Select the number of groups. Here, K = 3.

02

Assign

Put each customer in the nearest cluster.

03

Update

Recalculate each cluster's mean position.

04

Repeat

Stop when assignments no longer change.

K = number of groups · Means = average positions (centroids)

THE ELBOW RULE

More clusters are not always better.

3reasonable K

Within-cluster variation falls sharply from K=1 to K=3, then improves more slowly.

Note: The elbow method is a heuristic, not a guarantee of the best K.

MARKETING ANALYTICS
BASE R · REPRODUCIBLE

A few lines of R.
Useful customer insights.

This is the same illustrative dataset. No extra R packages are needed.

# Customer preference data
savings <- c(9,8,9,8,2,3,1,2,7,8,6,7)
agent   <- c(2,3,3,1,9,8,9,7,8,9,8,9)
X <- data.frame(savings, agent)

set.seed(123)
fit <- kmeans(X, centers = 3, nstart = 25)
fit$centers        # Group means
fit$cluster        # Group membership

plot(X, col = fit$cluster, pch = 19)
points(fit$centers, pch = 8, cex = 2)
